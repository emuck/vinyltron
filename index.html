Every display mode

The display

4,096 individually addressable LEDs.

A 64×64 HUB75 RGB LED matrix is a grid of 4,096 LEDs — each one driven independently, each capable of displaying any of 16.7 million colors at full PWM brightness control. The same HUB75 protocol drives LED walls at concerts and sports arenas, scaled down to a 7.5-inch panel that sits on a shelf or tucks inside a cabinet. At normal listening-room distance, the pixels disappear and what you see is vivid, physical light.

Live playback

Your music.
On the wall.
In real time.

Vinyltron listens to Volumio in real time — no polling, no lag. When a track starts, the matrix updates within a frame. When playback stops, it transitions gracefully to whatever idle mode you've chosen.

  • Album art resized and cropped to fill the full 64×64 display
  • Optional progress bar with configurable height and RGB color
  • Format badge: DSD64, DSD128, 24/96, 16/44.1, MP3, AAC, FLAC, and more
  • Handles pause, stop, track change, and reconnect — no stale art flashing
  • Starts automatically on boot — no manual restart needed

Live weather

Current conditions.
Pixel-perfect.

Live temperature, condition icon, high/low, humidity, wind, and moon phase — fetched from Open-Meteo (free, no API key required) and rendered entirely on the matrix in 64×64 pixels. AQI pulls from the air quality feed and color-codes by EPA tier. No cloud account, no subscription.

  • Automatic day/night switching with moon phase rendering
  • Secondary metric: humidity, wind speed, or AQI glyph
  • Configurable location, units, refresh interval, and fps
  • Falls back to mock data if coordinates aren't configured yet

Screensavers

Generative art.
Running on a $15 Pi.

Four simulation engines run directly on the Raspberry Pi, producing slowly evolving organic patterns that never repeat exactly. Each has configurable palette, speed, and reset interval from the Volumio UI — with advanced tuning parameters in config.toml.

  • Brian's Brain — three-state cellular automaton with selectable palette
  • Langton's Ant — multi-ant emergent highway patterns
  • Chaos Game — slowly rotating Sierpiński fractal
  • Gray-Scott — reaction-diffusion coral, spot, and worm morphologies

Photo manager

Your photos.
No SSH required.

A built-in browser UI at volumio.local:3018/photos lets you upload idle photos from any device on your home network — phone, tablet, or laptop. Set a single photo, pick from a folder, or randomize — all without touching the Pi.

  • Upload, select, delete, and randomize from phone or laptop
  • Accepts HEIC, JPEG, PNG — any photo your phone can take
  • Optional daily display schedule for photo-frame mode
  • Configurable port if 3018 conflicts with another service

Hardware

A weekend build.
A permanent fixture.

One Pi, one panel, one Bonnet. The Adafruit RGB Matrix Bonnet handles level shifting and hardware PWM timing so the matrix renders clean and flicker-free. A separate 5V supply keeps the Pi stable under full matrix load. Fits neatly inside an AV cabinet or on a shelf.

  • No dedicated software account or cloud service required
  • The Bonnet isn't required — direct GPIO wiring works too, with a retro-flicker charm
  • Pi 5 compatible in software-pulse mode; Pi 3B for hardware PWM
  • Full hardware setup, BOM, and wiring guide in docs/hardware.md

Install

SSH in once.
Then it
just runs.

Download the latest release zip, copy it to the Pi, and run volumio plugin install. The installer builds the matrix library from source (~25 min on a Pi 3B) and configures everything automatically. One reboot, then configure from the Volumio plugin settings page.

Full walkthrough in the install guide. Bonnet wiring and power in hardware setup.

↓ Download vinyltron.zip
# copy the release zip to your Pi $ scp vinyltron.zip volumio@volumio.local:~ # SSH in and install $ ssh volumio@volumio.local $ volumio plugin install vinyltron.zip # builds rpi-rgb-led-matrix (~25 min on Pi 3B) # configures boot files for hardware PWM # reboot to activate PWM boot settings $ sudo reboot # configure in Volumio → Plugins → Vinyltron
